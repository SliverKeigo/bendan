# 状态查询

状态命令仅由配置的管理员帐号执行，适合直接在 QQ 内确认机器人和当前会话的运行情况。

## `//status`

```text
//status
```

返回：

- OneBot WebSocket 当前是否已连接；
- Bendan 本次启动后的运行时间；
- 已加载的中文动作与英文别名数量；
- 当前会话是否处于静默状态。

示例：

```text
Bendan 状态
OneBot：已连接
运行时间：2小时14分8秒
动作词表：中文 33，英文 12
当前会话：正常
```

## `//hush status`

```text
//hush status
```

查询当前群或私聊是否已被静默：

- 未静默时返回“当前会话未静默”；
- 静默时返回剩余时间和预计恢复时间。

静默控制本身仍由回复 Bendan 后发送“别说话”“闭嘴”“安静”或“说话”完成。详情见 [功能一览](/guide/features#静默控制)。
