# 动作词表

动作词表决定哪些消息会被识别为动作，以及最终如何表达。它在运行目录以 `actions.json` 保存。

## 初始化词表

首次使用时复制仓库中的示例文件：

```sh
cp actions.json.example actions.json
```

如果没有 `actions.json`，Bendan 会使用程序内置的默认词表；但要通过管理员命令修改词表，需要创建该运行时文件。

## 文件格式

词表分为两组：

- `zh`：中文动作与输出动作的映射；
- `latin`：不区分大小写的英文别名与输出动作的映射。

```json
{
  "zh": {
    "摸": "摸了",
    "摸摸": "摸了摸",
    "挥": "挥了挥"
  },
  "latin": {
    "rua": "揉了揉",
    "wave": "挥了挥"
  }
}
```

例如配置了 `"wave": "挥了挥"` 后，发送 `wave 对方` 会生成：

```text
发送者 挥了挥 对方！
```

## 自动热重载

Bendan 每秒检查一次运行时词表：

1. 保存有效 JSON 后，词表会在最多一秒内替换。
2. 修改不需要重启容器或重新编译。
3. JSON 格式错误、空词表或包含空动作名时，Bendan 保留上一份有效词表并写入错误日志。

容器部署时，`actions.json` 被挂载到 `/etc/bendan/actions.json`。请确认该挂载路径可写，否则管理员无法通过命令更新词表。

## 管理员命令

只有管理员 QQ `1226355793` 可以使用以下指令：

| 指令 | 作用 |
| --- | --- |
| `//actions` | 查看词表路径、动作数量与最后加载时间。 |
| `//actions list` | 列出当前中文动作和英文别名。 |
| `//actions reload` | 立即从文件重新加载。 |
| `//actions add zh 挥 挥了挥` | 添加或更新一个中文动作。 |
| `//actions add latin wave 挥了挥` | 添加或更新一个英文别名。 |
| `//actions remove zh 挥` | 删除一个中文动作。 |
| `//actions remove latin wave` | 删除一个英文别名。 |

添加和删除会原子写入词表文件，并立即重载。建议用 `//actions list` 确认结果。

## 编写建议

- 输出值写完整的动词形式，例如 `抱了抱`、`挥了挥`。
- 英文别名使用小写；匹配时仍不区分大小写。
- 避免让动作名与常用聊天短语冲突，避免误触发自动回应。
- 大范围改词表前先备份：`cp actions.json actions.json.bak`。
