# 功能一览

## 动作

动作支持三种目标指定方式：回复消息、提及目标、直接给出目标文字。动作可以加 `/`，也可以直接发送“动作 + 目标”。

| 输入方式 | 示例 | 输出形式 |
| --- | --- | --- |
| 回复后发送动作 | 回复某人的消息后发送 `摸` | `发送者 摸了摸对方！` |
| 回复后指定部位 | 回复某人后发送 `摸 头` | `发送者 摸了摸对方的头！` |
| 提及目标 | `摸 @Bendan` | `发送者 摸了摸Bendan！` |
| 直接指定 | `抱 对方` | `发送者 抱了抱对方！` |
| 自然语序动作 | `比心 对方` | `发送者 给对方比了个心！` |
| 英文别名 | `highfive 对方` | `发送者 和对方击了个掌！` |

内置词表包含 46 个中文动作和 21 个英文别名。常见中文动作包括摸、抱、拍、戳、亲、揉、捏、蹭、比心、击掌、握手和举高高等；英文别名包括 `rua`、`hug`、`pet`、`headpat`、`cuddle`、`wave`、`feed`、`highfive` 和 `handshake` 等。完整词表可由 `actions.json` 自定义。

## `/me` 状态消息

发送：

```text
/me 喝茶
```

Bendan 会在当前会话发送：

```text
发送者 喝茶！
```

## 查询身份与会话

```text
//whoami
```

返回当前发送者 QQ 号与会话 ID，适合用来确认机器人当前收到的是哪个群或私聊。

## 自动回应

Bendan 会对部分常见语句进行半随机回应：

- 单独发送 `？`
- `看看……`
- `是……吗`、`是不是……`
- `有没有……`
- `能不能……`、`会不会……`、`可不可以……`、`行不行……`、`好不好……`
- `要不要……`、`该不该……`、`值不值得……`
- `A 还是 B`（通过 `{left}`、`{right}`、`{choice}` 占位符生成回应）
- `/没关系` 或 `/没事的`

自动回应默认作为普通群消息直接发送，不引用触发消息。只有需要保留明确上下文的交互（例如用户回复另一条消息触发特定行为）才会使用引用回复。自动回应按用户和会话进行短暂冷却，避免重复刷屏。

## 静默控制

只有消息明确指向 Bendan 时，静默控制才会触发：

- 回复 Bendan 的消息，并在正文中包含静默关键词；
- 直接 `@Bendan`，并在正文中包含静默关键词。

静默关键词采用包含匹配，当前包括“别说话”“不要说话”“别讲话”“不要讲话”“闭嘴”“住嘴”“安静”“别吵”和“消停”。例如“我求你闭嘴🙏”和“麻烦你别说话了”都能触发。Bendan 会在当前会话静默 30 分钟。

同样通过回复或 `@Bendan`，并在正文中包含“说话”，可以提前恢复。普通群成员之间使用这些词不会触发静默。

## 受限功能

以下能力仅限配置的管理员：

- Go 与 JavaScript 代码执行：`//go`、`//js`
- 动作词表查看、热重载、添加与删除
- 运行状态查询：`//status`、`//hush status`

普通成员发送这些命令时不会得到执行结果。
