# 功能一览

## 动作

动作支持三种目标指定方式：回复消息、提及目标、直接给出目标文字。动作可以加 `/`，也可以直接发送“动作 + 目标”。

| 输入方式 | 示例 | 输出形式 |
| --- | --- | --- |
| 回复后发送动作 | 回复某人的消息后发送 `摸` | `发送者 摸了 对方！` |
| 回复后指定部位 | 回复某人后发送 `摸 头` | `发送者 摸了 对方的头！` |
| 提及目标 | `摸 @Bendan` | `发送者 摸了 Bendan！` |
| 直接指定 | `抱 对方` | `发送者 抱了 对方！` |
| 英文别名 | `rua 对方` | `发送者 揉了揉 对方！` |

内置词表包含常见中文动作，如摸、抱、拍、戳、亲、揉、捏、蹭、咬、夸、举高高等；也支持 `rua`、`hug`、`kiss`、`pat`、`poke`、`highfive` 等英文别名。完整词表可由 `actions.json` 自定义。

## `/me` 状态消息

发送：

```text
/me 喝茶
```

Bendan 会在当前会话发送：

```text
发送者 喝茶！
```

## 查询身份与会话

```text
//whoami
```

返回当前发送者 QQ 号与会话 ID，适合用来确认机器人当前收到的是哪个群或私聊。

## 自动回应

Bendan 会对部分常见语句进行半随机回应：

- 单独发送 `？`
- `看看……`
- `是……吗`
- `有没有……`
- `能不能……`
- `/没关系` 或 `/没事的`

自动回应按用户和会话进行短暂冷却，避免重复刷屏。

## 静默控制

回复 Bendan 的消息并包含“别说话”“闭嘴”或“安静”，Bendan 会在该会话静默 30 分钟。回复并包含“说话”可提前恢复。

## 受限功能

以下能力仅限配置的管理员：

- Go 与 JavaScript 代码执行：`//go`、`//js`
- 动作词表查看、热重载、添加与删除

普通成员发送这些命令时不会得到执行结果。
